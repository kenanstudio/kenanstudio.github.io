Unity · Physics Tool

3D Collider

Accurate collider generation for models where a simple solid collider is not enough.

View on Unity Asset Store

Preserve the spaces that matter.

3D Collider detects surfaces and generates Mesh Colliders that can preserve tunnels, holes, windows, passages and concave spaces instead of filling an entire model with one simplified volume.

  • Surface-based non-convex Mesh Colliders for static geometry
  • Closed convex Mesh Colliders for Rigidbody workflows
  • Support for complex, concave and open source meshes
  • Adjustable generation settings and Scene view visualization
  • Built-in, URP and HDRP compatible
  • No external package dependencies
