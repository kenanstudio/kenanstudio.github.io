Featured Unity Tool

3D Collider

A Unity Editor tool for generating colliders from complex meshes while preserving important spaces such as openings, holes, tunnels and passages.

Two workflows for different physics needs.

  • Surface-based MeshCollider generation for static geometry
  • Preserves openings, holes, tunnels and passages
  • Oriented compound BoxCollider generation for Rigidbody objects
  • Adjustable Accuracy with real-time Editor preview
  • Closed-mesh validation for Convex generation
  • Built-in, URP and HDRP compatible
